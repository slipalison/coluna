Coluna v0.1.0

Coluna basáltica é o prisma que a lava deixa ao esfriar devagar.

É de onde vem o grid, as ripas das barras e a recusa a cantos arredondados. Esta página é pintada pelo CSS que o pacote publica, sem uma linha de diferença — se um token quebrar, ela quebra junto.

npm install @slipalison/coluna
import "@slipalison/coluna/styles.css";

Tema

três estados, dois temas

light e dark escrevem data-theme no elemento. system remove o atributo — é isso que deixa a media query voltar a mandar, e o que faz a tela acompanhar se você mudar o tema do sistema operacional com a página aberta. Experimente: escolha Sistema aqui e troque o tema do seu aparelho.

Cor

só o papel, nunca o valor

Duas camadas: a primitiva guarda o valor (--co-amethyst-500) e a semântica guarda o papel (--co-accent). Só a semântica muda com o tema, e componente nenhum lê primitiva. Os valores abaixo são lidos do navegador agora — trocando o tema acima, eles mudam.

Espaço e forma

o nome do token é o número de pixels

Um --co-space-6 diz onde encaixa; um --co-space-md exigiria decorar a tabela. O raio máximo do sistema é 4px e a maior parte dos componentes usa 0 — basalto lasca em coluna hexagonal, não em pílula.

As recusas

o que não entra, e por quê

Design system morre de duas formas opostas: virando uma coleção de <div> com props de estilo, ou virando um catálogo que tenta prever toda tela do produto. A fronteira precisa estar escrita, senão é decidida caso a caso, por quem estiver com pressa.

Não existe Button size="sm" 44px é o alvo mínimo que um polegar acerta. Se isso fosse um aviso na documentação, o sm apareceria em produção na primeira sexta-feira.
O aviso não tem variante de erro Aviso informa, nunca bloqueia. Erro de verdade — entrada sem significado — não é um aviso: é uma mensagem junto do campo que a produziu, e isso é do aplicativo.
Um vermelho só, e ele tem dono Apagar a conta apaga os dados de verdade. Vermelho não decora erro de digitação nem repreende quem comeu mais do que planejou.
Nada aqui sabe o que é uma refeição MacroBar recebe nome, valor e alvo. O teste prático: se a prop for um objeto do domínio, o componente está do lado errado da linha — e todo ajuste na API do Basalto viraria uma versão nova do design system.
A barra não grampeia o excedente por baixo dos panos Passar do alvo é informação. O desenho satura em 100%; o número ao lado continua contando a verdade, e nada muda de cor.
Esta página é gerada por scripts/gerar-referencia.mjs a partir de dist/styles.css e do mapa de ícones em src/atoms/Icon.tsx. Ela usa a mesma marcação que os componentes React emitem, mas não executa o React — o contrato aqui é o CSS. Código em github.com/slipalison/coluna.
